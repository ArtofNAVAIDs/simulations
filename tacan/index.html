TACAN Simulation

This simulation illustrates how TACAN azimuth is derived from the 15 Hz and 135 Hz modulated RF pulse train, in conjuntion with the North Reference Bursts (NRBs) and Auxiliary Reference Bursts (ARBs). For a more detailed explanation, view the tutorial.
